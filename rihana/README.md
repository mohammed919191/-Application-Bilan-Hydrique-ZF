# 🌸 مدرسة ريحانة

موقع تعليمي عربي لطفلة عمرها 6 سنوات، فيه معلمة صوتية (المعلمة سلمى 👩‍🏫) تشرح وتسأل وتشجّع.

## 🧭 رحلة ريحانة (المسار المرتب)
صُمّم ليناسب طفلة تتشتت بسهولة:
- **خطة يومية من 3 دروس قصيرة** (عربية، رياضيات، لغة أجنبية) مع زر كبير واحد «▶ ابدئي».
- **كل درس 3 إلى 5 دقائق** بخطوات واضحة (نقاط في الأعلى): تعرّفي ← اسمعي واختاري ← اكتبي.
- **لا يوجد سؤال يحتاج قراءة** قبل درس القراءة: كل التعليمات مسموعة، والإجابات صور أو أصوات.
- **ترتيب منطقي**: حروف سهلة أولًا (م، ب)، ثم الفتحة باستعمال الحروف التي تعرفها، ثم الضمة، ثم الكسرة، ثم السكون والمدّ، ثم قراءة كلمات من حروف تعلّمتها فقط.
- **الدرس التالي يُفتح فقط بعد الإتقان** (60% فأكثر)، وإلا تعيد الدرس.
- **استراحة حركة بعد كل درس** (قفز، تصفيق، تنفّس) لإعادة التركيز.
- **بدون مؤقت ضغط** افتراضيًا (يمكن تفعيله من ركن الوالدين).

## ماذا تتعلّم ريحانة؟ (اللعب الحر)

| المادة | الدروس |
|---|---|
| 📝 العربية | الحروف الـ28 مع الصوت والصورة وأشكال الحرف (وحده/أول/وسط/آخر) · الحركات (الفتحة، الضمة، الكسرة، السكون) وحروف المد · قراءة كلمات مقطعًا مقطعًا · كتابة الحروف بالإصبع · لعبتان |
| 🔢 الرياضيات | الأعداد 0–20 مع العدّ · لعبة العدّ · الجمع ➕ · الطرح ➖ · الضرب ✖️ · القسمة ➗ (كل درس يبدأ بشرح بالصور ثم لعبة) · كتابة الأرقام |
| 🇫🇷 الفرنسية / 🇬🇧 الإنجليزية | الحروف A–Z مع كلمة وصورة ومعنى بالعربية · الألوان · الأعداد · الحيوانات · الفواكه · التحية · كتابة الحروف · لعبة اسمعي واختاري |

## كيف تعمل «المعلمة الذكية»؟
- **تتكلم** بالعربية والفرنسية والإنجليزية (صوت المتصفح نفسه، بدون إنترنت إضافي).
- **تتذكر أخطاء ريحانة** وتعيد عليها الحروف والكلمات الصعبة أكثر.
- **تغيّر الصعوبة** في الحساب تلقائيًا: 3 إجابات صحيحة متتالية ← أسئلة أصعب، خطآن ← أسهل.
- **تقترح درس اليوم** في الصفحة الرئيسية حسب نقاط الضعف.
- **التحفيز**: نجوم ⭐، ملصق جديد 🎁 كل 10 نجوم، احتفالات، مؤقت لكل سؤال، وهدف دراسة يومي (20 دقيقة افتراضيًا) ثم تقترح الاستراحة.

## ⚙️ ركن الوالدين
زر ⚙️ أعلى الصفحة (محمي بسؤال ضرب بسيط): وقت الدراسة لآخر 7 أيام، نسبة الإجابات الصحيحة لكل درس، ما يحتاج تدريبًا، سرعة الصوت، الهدف اليومي، مؤقت الأسئلة، ومسح التقدّم.

## التشغيل
- افتحوا `rihana/index.html` في Chrome أو Safari (على الهاتف أو الحاسوب).
- أو فعّلوا **GitHub Pages**: Settings ← Pages ← Branch: هذا الفرع ← `/ (root)` ثم افتحوا الرابط مع `/rihana/`.
- التقدّم محفوظ في المتصفح نفسه (على هذا الجهاز).

> إذا لم يكن الصوت العربي يعمل: على أندرويد ثبّتوا «Google Text-to-Speech» وأضيفوا العربية، وعلى آيفون: الإعدادات ← تسهيلات الاستخدام ← المحتوى المنطوق ← الأصوات ← العربية.
